# Code of Conduct

## Our pledge

We want Vole to be a project people can contribute to without having to armour up
first. Everyone participating — filing an issue, opening a pull request, reviewing
one, or answering a question — is expected to treat others with respect.

## Expected behaviour

- Assume good faith. Most disagreements here are about a technical claim, and most
  technical claims can be settled by measuring something.
- Be specific. "This is wrong" helps nobody; "this under-counts because Claude Code
  writes the same message id several times" is a contribution.
- Accept that maintainers may say no. A rejected feature is not a rejected person,
  and the reasoning belongs in the thread so the next person can read it.

## Unacceptable behaviour

Harassment, personal attacks, discriminatory language, sustained disruption, or
publishing someone's private information without their consent.

## Scope

This applies in issues, pull requests, discussions, commit messages and any other
project space.

## Reporting

Report conduct concerns privately to the maintainers by opening a
[security advisory](https://github.com/launchsafe/vole/security/advisories/new),
which is private, or by contacting a maintainer directly. Reports are handled
confidentially. Maintainers who do not follow this code face the same consequences
as anyone else.
